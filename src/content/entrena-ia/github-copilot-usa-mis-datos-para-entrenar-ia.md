Sí, en los planes individuales, por default desde el 24 de abril de 2026 — antes de esa fecha la política era distinta. GitHub anunció en marzo de 2026 que los datos de interacción (entradas, salidas, fragmentos de código y su contexto) de usuarios de Copilot Free, Pro y Pro+ se usan para entrenar y mejorar sus modelos de IA, salvo que la persona decida no participar. Es una cláusula de opt-out, no de opt-in: si no apagas la opción a mano, tus interacciones se recolectan. Fuente: blog oficial de GitHub, "Updates to GitHub Copilot interaction data usage policy", verificado el 9 de septiembre de 2026.

## Cómo optar por no participar

Ve a github.com/settings/copilot/features y apaga "Allow GitHub to use my data for AI model training", en la sección de privacidad. El cambio detiene la recolección a partir de ese momento — no revierte lo que ya se procesó antes de que lo desactivaras.

## El matiz: código de repos privados "en sesión" sí cuenta

GitHub dice que el código de tus repositorios privados "en reposo" no se usa para entrenar. Pero el código que Copilot lee como contexto activo durante una sesión —lo que tienes abierto en el editor mientras te da sugerencias— sí se considera "dato de interacción" y puede quedar incluido si no desactivaste la opción, sin importar que el repositorio en sí sea privado.

## Plan individual vs. empresarial

Esta política aplica solo a Copilot Free, Pro y Pro+ — planes de una persona. Copilot Business y Copilot Enterprise quedan explícitamente excluidos de este cambio: si usas Copilot a través de una licencia de tu empresa, es probable que no te aplique, vale la pena confirmarlo con quien administra la cuenta.
