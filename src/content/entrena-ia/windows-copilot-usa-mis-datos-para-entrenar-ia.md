Depende de qué parte de la IA de Windows uses. Tus conversaciones con Copilot se usan para entrenar los modelos de Microsoft salvo que tú desactives esa opción — el ajuste existe, pero el punto de partida es que sí participas. Recall, la función más polémica de Windows —que toma capturas periódicas de tu pantalla para que luego puedas "buscar en tu memoria" digital— tiene una historia distinta: se anunció en 2024, se pausó por la presión pública sobre cómo manejaba esos datos, y regresó como una función que tienes que activar tú mismo durante la configuración, con todo almacenado localmente y cifrado. Fuente: FAQ de Privacidad de Microsoft Copilot, verificado el 23 de agosto de 2026.

## Cómo optar por no participar

En la app de Copilot, ve a Cuenta → Privacidad → Entrenamiento con actividad de conversación, y desactiva la opción. Esto detiene el uso de tus conversaciones futuras para entrenar modelos de IA — pero Microsoft aclara que sí puede seguir usando esas conversaciones para otros fines, como mejora del producto, seguridad, cumplimiento normativo o publicidad, que no se cubren con este mismo interruptor. Para Recall, si nunca lo activaste durante la instalación de tu equipo, simplemente no está corriendo; si lo activaste y te arrepentiste, puedes apagarlo en Configuración → Privacidad y seguridad → Recall y capturas de pantalla.

## El caso de GitHub Copilot es distinto — y también tuyo si programas

Si usas GitHub Copilot para programar, aplica una regla diferente a la de Windows Copilot: desde abril de 2026, el código, los prompts y la telemetría de cuentas individuales Free, Pro y Pro+ se usan automáticamente para entrenar modelos de IA, salvo que lo desactives en Configuración de GitHub → Copilot → Privacidad. Es la misma empresa matriz, pero una decisión de producto separada — vale la pena revisarla aparte si programas con esa herramienta.
