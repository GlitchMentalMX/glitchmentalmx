No. Microsoft lo declara como "Important" en su propia documentación técnica: "Prompts, responses, and data accessed through Microsoft Graph aren't used to train foundation LLMs, including those used by Microsoft Copilot" ("los prompts, las respuestas y los datos a los que se accede a través de Microsoft Graph no se usan para entrenar los modelos de lenguaje base, incluidos los que usa Microsoft Copilot"). Esto cubre el contenido que Copilot toca dentro de toda la suite: tus documentos de Word, hojas de Excel, presentaciones de PowerPoint, correos de Outlook y archivos en OneDrive o SharePoint — todo se procesa bajo los mismos compromisos contractuales que ya protegen el resto de tu contenido de Microsoft 365, sin salir de ahí para entrenar modelos que después usan otros clientes. Fuente: documentación oficial de Microsoft Learn sobre privacidad de Copilot, verificado el 31 de agosto de 2026.

## Tampoco el feedback que envías

Microsoft aclara un matiz que suele pasar desapercibido: sí puede usar el feedback opcional que envías sobre una respuesta de Copilot para mejorar el producto —igual que hace con cualquier otro servicio de Microsoft 365— pero es explícito en que "we don't use this feedback to train the foundation LLMs used by Microsoft Copilot" ("no usamos este feedback para entrenar los modelos de lenguaje base que usa Microsoft Copilot"). Es decir: mejora de producto y entrenamiento de modelo son dos cosas separadas, y la segunda queda excluida incluso cuando tú das retroalimentación activamente.

## No hay opt-out porque no hace falta uno

A diferencia de Microsoft Copilot como app independiente (copilot.microsoft.com), donde sí existe un interruptor de entrenamiento porque el entrenamiento está activado por default, aquí no hay nada que desactivar: la protección aplica automáticamente a toda cuenta de Microsoft 365 comercial, sin que un administrador tenga que configurar nada.
