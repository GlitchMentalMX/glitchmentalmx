## Qué cambia el precio final

Ojo con esto: "GitHub Copilot" y "Microsoft Copilot" son dos productos distintos de la misma empresa, con precios y funciones que no tienen nada que ver entre sí — este artículo cubre el asistente de código para programadores (GitHub Copilot), no el asistente general integrado a Office. Si buscabas ese, es el que ya cubrimos aparte en esta misma serie. Dicho esto: el plan Pro de GitHub Copilot cuesta $10 USD al mes por usuario. Arriba existen [Pro+](/articulos/cuanto-cuesta-github-copilot-pro-plus-hoy/) ($39 USD al mes, con un presupuesto mensual de créditos de IA mucho mayor que Pro; la lista de modelos disponibles es la misma) y Max ($100 USD al mes, para flujos de trabajo agénticos de alto volumen) — Pro es el punto de entrada real para uso diario, no el techo. Solo se cobra mes a mes: la documentación de GitHub no ofrece plan anual para las cuentas personales. También existe un descuento total: Pro es gratis para docentes verificados y para mantenedores de proyectos de código abierto populares, y los estudiantes verificados tienen su propio plan, Copilot Student, también sin costo.

## Qué incluye el plan pagado

Pro da autocompletado de código y sugerencias de edición ilimitadas (el plan gratuito tiene un tope de 2,000 autocompletados al mes), acceso a Cloud Agent y revisión de código, acceso a agentes de terceros como Claude Code y Codex dentro del ecosistema de GitHub, selección de modelo, y 1,000 créditos base más 500 créditos flexibles al mes para funciones premium (Pro+ sube a 3,900 base más 3,100 flexibles). El plan gratuito ya incluye autocompletado limitado y acceso a un par de modelos básicos — funcional para probarlo, insuficiente para uso diario intensivo.

## El nombre "Copilot" es el punto de confusión más común de toda esta serie

Microsoft usa "Copilot" como marca paraguas para varios productos distintos: el de Office (que ya cubrimos aparte en esta serie), el de GitHub, y hasta el que viene integrado en Windows. Si programas y buscas cuánto cuesta Copilot, este es el artículo correcto; si usas Word, Excel u Outlook, el precio que te interesa es el de Microsoft 365 Premium, no este.
