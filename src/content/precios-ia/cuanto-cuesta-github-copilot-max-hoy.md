## Qué cambia el precio final

GitHub Copilot Max es el escalón más alto de los planes individuales de GitHub Copilot. Está arriba de [GitHub Copilot Pro](/articulos/cuanto-cuesta-github-copilot-hoy/) ($10 USD al mes) y de [Pro+](/articulos/cuanto-cuesta-github-copilot-pro-plus-hoy/) ($39 USD al mes). Es el asistente de código para programadores, no el Copilot de Office ni el de Windows.

La página oficial de planes lista Max en $100 USD al mes. El sitio convierte esa cifra a pesos con el FIX de Banxico, así que el número que ves aquí es una referencia, no lo que tu banco va a cargar: la página de GitHub no aclara si ese precio ya trae impuestos. En la página oficial que consultamos hoy solo aparece cobro mensual, sin opción anual.

## Qué incluye el plan pagado

Max incluye todo lo de Pro+. GitHub lo plantea para quien tiene un uso intenso y sostenido de IA y quiere el mayor presupuesto de créditos que ofrece un plan individual. No cambia la lista de modelos: la página oficial muestra los mismos modelos disponibles en todos los planes de pago, y las sugerencias en línea son ilimitadas.

Lo que cambia es el presupuesto de GitHub AI Credits, que es lo que se gasta con el modo agente, la revisión de código, el cloud agent o Copilot CLI (1 crédito equivale a $0.01 USD):

- Pro+: $39 USD de base más $31 USD de asignación flexible, $70 USD al mes en total.
- Max: $100 USD de base más $100 USD de asignación flexible, $200 USD al mes en total (20,000 créditos).

Eso es casi tres veces el presupuesto de Pro+ por poco más del doble de precio. El consumo depende del modelo que uses.

## Para quién sí alcanza este plan, y para quién se queda corto

Max tiene sentido si ya agotas los créditos de Pro+ de forma habitual: delegas tareas largas al cloud agent o trabajas todos los días con modelos que consumen muchos créditos. Si Max te evita frenar a mitad de mes por falta de créditos, los $100 USD se justifican con trabajo real.

Se queda corto, o sobra, en casi todo lo demás. Si usas Copilot sobre todo para autocompletar, eso es ilimitado desde Pro y no gasta créditos, así que pagar Max por eso es tirar dinero. Empieza en Pro o Pro+ y sube solo si te quedas sin créditos. Tampoco es un plan de equipo: para eso existen Business y Enterprise.
