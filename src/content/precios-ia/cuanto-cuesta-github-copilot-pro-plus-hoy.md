## Qué cambia el precio final

GitHub Copilot Pro+ es el segundo escalón de los planes individuales de GitHub Copilot: está arriba de [GitHub Copilot Pro](/articulos/cuanto-cuesta-github-copilot-hoy/) ($10 USD al mes) y abajo de Max ($100 USD al mes). Es el asistente de código, no el Copilot de Office ni el de Windows.

La página oficial de planes lista Pro+ en $39 USD al mes. El sitio convierte esa cifra a pesos con el FIX de Banxico, así que el número que ves aquí es una referencia, no lo que tu banco va a cargar: la página de GitHub no aclara si ese precio ya trae impuestos. En la página oficial que consultamos hoy solo aparece cobro mensual, sin opción anual.

## Qué incluye el plan pagado

Aquí hay un matiz importante: lo que cambia entre Pro y Pro+ no es la lista de modelos. La página oficial muestra los mismos modelos disponibles en Free, Pro, Pro+ y Max, y las completaciones de código son ilimitadas desde Pro.

Lo que sí cambia es el presupuesto de GitHub AI Credits, que es lo que se gasta cuando usas el chat, el modo agente, la revisión de código, el cloud agent o Copilot CLI (1 crédito equivale a $0.01 USD):

- Pro: $10 USD de base más $5 USD de asignación flexible, $15 USD al mes en total.
- Pro+: $39 USD de base más $31 USD de asignación flexible, $70 USD al mes en total.

GitHub avisa que la asignación flexible puede cambiar con el tiempo. Además, Pro+ incluye iniciar y dar seguimiento a tareas desde la página o el panel de agentes de GitHub, algo que la tabla marca como no incluido en Pro.

## Para quién sí alcanza este plan, y para quién se queda corto

Pro+ tiene sentido si ya te topas con el límite de créditos de Pro: usas el modo agente a diario, delegas tareas al cloud agent o corres sesiones largas con modelos de frontera que consumen más créditos. Pagas $29 USD más para tener casi cinco veces el presupuesto de créditos.

Se queda corto, o sobra, si usas Copilot sobre todo para autocompletar: eso es ilimitado desde Pro y no gasta créditos. Tampoco es para equipos: no incluye administración de usuarios, métricas de uso, SSO ni indemnización de propiedad intelectual, que son de Business y Enterprise. Para más volumen agéntico, el escalón siguiente es Max, con $200 USD en créditos.
