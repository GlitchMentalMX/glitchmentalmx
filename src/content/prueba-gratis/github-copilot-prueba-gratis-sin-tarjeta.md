## ¿Qué tan gratis es la prueba de GitHub Copilot?

El plan Free de GitHub Copilot es real y no pide tarjeta — la propia página oficial de planes lo dice de forma explícita: "No se requiere tarjeta de crédito", con 2,000 autocompletados al mes y acceso a un par de modelos básicos. Pero para Pro, Pro+ o Max, la documentación oficial de GitHub describe un proceso de suscripción que va directo al cobro: hay que "ingresar y confirmar tu información de facturación y datos de pago" antes de poder activar cualquiera de esos planes, y el proceso descrito hoy no incluye ningún periodo de prueba.

Vale aclarar que en el pasado GitHub sí ofreció una prueba de 30 días de Copilot Pro que también pedía tarjeta por adelantado, con cobro automático si no cancelabas a tiempo — pero esa prueba ya no aparece descrita en la documentación oficial vigente. Hoy la única ruta sin pagar es quedarte en el plan Free, no una prueba temporal de Pro.
