## ¿Qué tan gratis es la prueba de Le Chat?

Le Chat tiene un plan gratuito permanente que no pide tarjeta, con límites diarios razonables para conversar y programar. Pero según la página oficial de precios de Mistral AI, el plan Pro ($14.99 USD al mes) no aparece con ningún periodo de prueba: se sube de plan pagando directo desde la cuenta, sin una ventana intermedia para probar sin compromiso el uso ampliado de mensajes, la búsqueda web extendida o los $30 USD mensuales en créditos de API que trae Pro.

El plan Pro Education, a $5.99 USD al mes para estudiantes verificados, tampoco cambia esto: es un descuento sobre el mismo pago directo, no una prueba gratuita.
