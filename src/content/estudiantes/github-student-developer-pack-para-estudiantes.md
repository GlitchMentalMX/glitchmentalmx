## ¿El GitHub Student Developer Pack es gratis?

Sí. GitHub lo presenta como un paquete de herramientas profesionales y ofertas de socios "sin costo" para estudiantes verificados. No es un descuento sobre un plan de pago: no pagas por el paquete.

Ojo con lo que sí tiene fecha de caducidad. El Pack no es un solo beneficio, sino una lista de ofertas de empresas distintas, y cada una trae su propio plazo y sus propios límites. Según la página oficial de GitHub, por ejemplo:

- GitHub Pro y GitHub Copilot Student: gratis mientras seas estudiante. Copilot Student tiene límites en chat y agentes, y solo usa la selección automática de modelo.
- Microsoft Azure: 100 dólares en crédito para mayores de 18 años (hay una oferta aparte para 13 a 17).
- MongoDB Atlas: 50 dólares en crédito.
- Heroku: 13 dólares al mes durante 24 meses.
- Namecheap: un dominio .me y un certificado SSL, ambos por un año.
- Datadog: cuenta Pro gratis por 2 años.
- 1Password: gratis por un año.
- Cursos como Educative, Codedex o FrontendMasters: 6 meses cada uno.

La lista completa cambia con el tiempo, así que revisa la página oficial antes de contar con una oferta concreta.

## ¿Aplica en México?

La empresa no especifica si aplica en México. Ni la página del Pack ni las de GitHub Education para estudiantes mencionan listas de países o restricciones regionales, y tampoco dicen que México esté excluido. Por eso el veredicto es amarillo: no hay una promesa explícita para estudiantes mexicanos, solo la ausencia de una restricción publicada.

Lo que sí dice GitHub es quién califica: tener al menos 13 años, una cuenta personal de GitHub y estar inscrito en un programa que otorgue título o diploma (preparatoria, universidad, escuela en casa, etc.). Algunas ofertas del paquete tienen sus propios requisitos de edad.

## Cómo reclamarlo

1. Entra a la configuración de beneficios de educación de tu cuenta de GitHub (github.com/settings/education/benefits) y pulsa «Start an application».
2. Llena el formulario y envía la solicitud.

GitHub pide una prueba de que estás inscrito actualmente. Acepta una foto de tu credencial escolar con la fecha vigente, tu horario de clases, tu kárdex o una carta de la escuela que confirme que eres alumno. Si el formulario te pide un correo académico, agrégalo y verifícalo en tu cuenta antes de solicitar. Si tu escuela no da correos académicos, GitHub acepta documentos oficiales, como una página de la escuela o una carta con membrete, y vuelves a solicitar.

Si el dominio de tu correo escolar no es reconocido, GitHub indica escribir a su soporte de Education con el nombre completo de la escuela, su sitio web y el dominio del correo.

La página que consultamos no dice cuánto tarda la aprobación.

## Qué pasa cuando termina

La documentación que consultamos no explica cuánto dura el acceso al Pack completo ni cada cuánto se reverifica tu estatus. Lo que sí queda claro es que varios beneficios dependen de que sigas siendo estudiante, y que otros tienen plazos fijos propios (por ejemplo, los 24 meses de Heroku o el año de Namecheap). Si dejas de calificar, GitHub no promete conservar los beneficios; revisa cada oferta antes de usarla en un proyecto del que dependas.
