## ¿GitHub Copilot tiene descuento o plan gratis para estudiantes?

Sí: existe el plan Copilot Student, gratuito para estudiantes verificados a través de GitHub Education (el Student Developer Pack). No es un descuento sobre otro plan; es un plan aparte que no cuesta nada.

Ojo con lo que incluye. La documentación de GitHub dice que trae finalizaciones de código ilimitadas y una bolsa de créditos de IA, con chat y agentes de uso limitado. Solo puedes usar la selección automática de modelo (no eliges el modelo), y quedan fuera los agentes de terceros. Es menos que Copilot Pro, y la propia GitHub lo presenta así.

## ¿Aplica en México?

La empresa no especifica si aplica en México. Ni la página de GitHub Education ni la documentación de Copilot Student mencionan listas de países o restricciones regionales; tampoco dicen que México esté excluido. Por eso el veredicto es amarillo: no hay una promesa explícita para estudiantes mexicanos, solo la ausencia de una restricción publicada.

Lo que sí dice GitHub es quién califica: tener al menos 13 años, una cuenta personal de GitHub y estar inscrito en un programa que otorgue título o diploma (preparatoria, universidad, etc.).

## Cómo reclamarlo

Son dos pasos separados, y confundirlos es lo que más atora a la gente.

1. Verifica tu estatus en GitHub Education. GitHub pide un correo escolar o prueba con fecha de inscripción: foto de tu credencial con vigencia, horario de clases, kárdex o una carta de la escuela. Si tu escuela exige correo académico, tienes que agregarlo y verificarlo antes de solicitar.
2. Ya verificado, activa Copilot Student en la configuración de beneficios de educación de tu cuenta.

La documentación advierte que la activación puede tardar varios días después de la verificación. Si solo ves opciones de pago, no compres nada: espera y vuelve a intentar.

## Qué pasa cuando termina

GitHub revalida tu elegibilidad cada mes, así que el acceso depende de que sigas siendo estudiante verificado. La documentación que consultamos no explica qué ocurre con tu cuenta cuando dejas de serlo, y no dice que se te cobre automáticamente. Si te quedas sin el beneficio, GitHub ofrece Copilot Free (limitado) o los planes de pago.
