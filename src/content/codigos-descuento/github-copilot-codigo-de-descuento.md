## ¿Existe un código de descuento real para GitHub Copilot?

No. GitHub no ofrece códigos de descuento canjeables para Copilot Pro ni Pro+ — no hay un campo de "código promocional" al suscribirte, ni un mecanismo genérico de cupones para el público. El ahorro por facturación anual que GitHub tuvo antes (Pro a $100 USD al año, Pro+ a $390) ya no aparece en ninguna página oficial: hoy la página de planes y la documentación de GitHub solo muestran cobro mensual en dólares de EE.UU. (Pro $10 al mes, Pro+ $39 al mes), y el blog oficial de GitHub dice que quienes ya tenían plan anual lo conservan hasta que venza. Por eso ya no lo contamos como descuento vigente. No hay cupón ni código: el precio es el de lista.

## El otro canal real: Copilot gratis para estudiantes verificados

GitHub sí tiene un beneficio real y significativo para estudiantes: a través de GitHub Education y el Student Developer Pack, estudiantes verificados obtienen el plan Copilot Student sin costo. No es un descuento porcentual ni es Copilot Pro: la documentación lo describe con una bolsa de créditos de IA, selección automática de modelo y sin agentes de terceros. Lo conservas mientras mantengas tu estatus de estudiante verificado (GitHub revisa la elegibilidad cada mes). GitHub no publica una lista de países ni excluye a México, pero tampoco promete explícitamente que aplique ahí. Para activarlo, primero verificas tu estatus en GitHub Education con tu correo o credencial escolar, y después activas el plan Copilot Student desde la configuración de tu cuenta — son dos pasos separados, y la activación puede tardar algunos días. El blog oficial de GitHub menciona que aplicó cambios temporales a sus planes individuales (incluido Student) antes del paso a facturación por uso en junio de 2026; no publica fechas, así que no las damos.

## Por qué desconfiar de los "códigos GitHub Copilot" que circulan en sitios de cupones

Hay sitios de cupones que listan códigos genéricos de descuento para Copilot, pero ninguno está confirmado por GitHub, y el checkout de Copilot no tiene un campo para canjear ese tipo de código. El único ahorro real que sigue publicado —el programa para estudiantes— se gestiona directamente dentro de tu cuenta de GitHub, nunca con un cupón de terceros.
