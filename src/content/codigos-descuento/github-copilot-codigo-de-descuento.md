## ¿Existe un código de descuento real para GitHub Copilot?

No. GitHub no ofrece códigos de descuento canjeables para Copilot Pro ni Pro+ — no hay un campo de "código promocional" al suscribirte, ni un mecanismo genérico de cupones para el público. Lo único que la documentación oficial confirma como ahorro real es la facturación anual: Copilot Pro cuesta $10 USD al mes si pagas mensual, pero $100 USD al año si pagas por adelantado (equivalente a $8.33 al mes), un ahorro cercano al 17%. Copilot Pro+ sigue la misma lógica: $39 al mes o $390 al año. Igual que con el resto de esta serie, no es un cupón — es una condición de precio fija, sin necesidad de código.

## El otro canal real: Copilot gratis para estudiantes verificados

GitHub sí tiene un beneficio real y significativo para estudiantes: a través de GitHub Education y el Student Developer Pack, estudiantes verificados obtienen acceso gratuito a las funciones premium de Copilot. No es un descuento porcentual, es acceso completo sin costo mientras mantengas tu estatus de estudiante verificado (la elegibilidad se revisa mensualmente). Para activarlo, primero verificas tu estatus en GitHub Education con tu correo o credencial escolar, y después activas el plan Copilot Student desde la configuración de tu cuenta — son dos pasos separados, y la activación puede tardar algunos días. Vale la pena mencionar que este programa, junto con las nuevas suscripciones de Copilot Pro y Pro+, estuvo pausado temporalmente entre abril y mediados de junio de 2026 por la demanda de cómputo de los flujos de trabajo agénticos, pero las inscripciones ya estaban abiertas de nuevo al momento de esta verificación.

## Por qué desconfiar de los "códigos GitHub Copilot" que circulan en sitios de cupones

Hay sitios de cupones que listan códigos genéricos de descuento para Copilot, pero ninguno está confirmado por GitHub, y el checkout de Copilot no tiene un campo para canjear ese tipo de código. Los únicos ahorros reales —facturación anual y el programa para estudiantes— se gestionan directamente dentro de tu cuenta de GitHub, nunca con un cupón de terceros.
